# Les 16 Maisons (*al-Buyūt*) et les Grilles *Taskīn*

## 1. Classification structurale des 16 maisons `[A]`

Dans *Bulūgh al-Amal* (Bāb IV) et *al-Falak al-Mashḥūn* :
- **Pivots (*Awtād* / الأوتاد)** : `M1`, `M4`, `M7`, `M10` (force maximale).
- **Voisins des Pivots (*Mā yalī al-awtād* / ما يلي الأوتاد)** : `M2`, `M5`, `M8`, `M11` (force moyenne).
- **Déchus / Cadents (*Sawāqiṭ* / السواقط)** : `M3`, `M6`, `M9`, `M12` (faiblesse / chute).
- **Synthèse du thème** : `M13` (*al-Shāhid al-ayman* / Témoin droit / Demandeur), `M14` (*al-Shāhid al-aysar* / Témoin gauche / Sujet), `M15` (*al-Ḥākim* / *al-Qāḍī* / *al-Mīzān* — le Juge), `M16` (*ʿĀqibat al-ʿāqiba* — l'Issue de l'issue / Sentence).

## 3. Grilles de repos (*Taskīn*) `[B]`

> **Avertissement** : Une grille de *taskīn* (تسكين) est un **dispositif de placement fixe** (anneau de lecture), jamais une matrice génératrice des Mères aléatoires. Dans le *Bulūgh* (p. 56), al-Ṭūkhī mentionne trois tables : al-Zanātī, Abū al-ʿAbbās et celle des planètes. La grille ci-dessous est celle relevée chez les praticiens (`[B]`) :

### Taskīn al-Zanātī (praticiens `[B]`)
```text
M1=1121   M2=1222   M3=2111   M4=2212
M5=1111   M6=1212   M7=2122   M8=2221
M9=1122   M10=1221  M11=2112  M12=2211
M13=1112  M14=1211  M15=2121  M16=2222
```

### Clés de placement numériques
- **Abḍaḥ** (`1 / 2 / 4 / 8`) et **Bazdaḥ** (`2 / 7 / 4 / 8`) : clés de positionnement sur l'anneau (ne pas confondre avec les éléments).
- **Valeurs Abjad `[A]` (table des lettres) / `[B]-[C]` (attribution aux figures)** : utilisées pour les calculs numériques (attention : les formules métrologiques de conversion directe en cm/km sont classées `[D]` car absentes des traités).
