## 2. Fiches synthétiques (Couleur, Régime, Saraka Kassibo, Sens)

1. **Via (`1111`, *al-Ṭarīq*, *Tariki*)** — Blanc / diurne. Saraka : 4 grosses colas blanches (*dakabana woro*), 4 boules de *dèguè*, tissu blanc. Sens : route, cheminement solitaire, errance, figure neutre.
2. **Acquisitio (`2121`, *al-Qabḍ al-dāḫil*, *Mori Sumana*)** — Blanc / nocturne. Saraka : chameau blanc, turban, lait, *dèguè*, feuilles blanches. Sens : gain, acquisition, réussite matérielle.
3. **Albus (`2212`, *al-Bayāḍ*, *Albayada*)** — Blanc / diurne. Sens : paix, pureté, sagesse, intuition, clarté.
4. **Rubeus (`2122`, *al-Ḥumra*, *Lumara*)** — Rouge / diurne. Sens : colère, violence, sang, danger ; *Bulūgh* ch. 24 : mal dans le ventre (foie/rate) si en maison du malade.
5. **Carcer (`1221`, *al-ʿAqla*, *Mansa Solomani*)** — Régime diurne. Sens : prison, nœud, blocage durable, enfermement.
6. **Caput Draconis (`2111`, *al-ʿAtaba al-dāḫila*, *Maléju*)** — Blanc / diurne. Sens : seuil entrant, commencement favorable, élévation.
7. **Cauda Draconis (`1112`, *al-ʿAtaba al-ḫāriǧa*, *Lusiné*)** — Régime nocturne. Sens : seuil sortant, fin, chute, perte, sortie.
8. **Fortuna Major (`2211`, *al-Nuṣra al-dāḫila*, *Nunkoro*)** — Rouge / nocturne. Sens : grande victoire, secours solide, protection durable.
9. **Populus (`2222`, *al-Ǧamāʿa*, *Jamati Moussa*)** — Rouge / nocturne. Sens : foule, assemblée, multitude, neutre (reflète les figures voisines).
10. **Amissio (`1212`, *al-Qabḍ al-ḫāriǧ*, *N'gansa*)** — Régime diurne. Sens : perte, dispersion, dépense, fuite.
11. **Puella (`1211`, *Naqī al-ḫadd*, *Tontigi*)** — Noir / nocturne. Sens : beauté, charme, douceur, jouvence, paix affective.
12. **Puer (`1121`, *al-Ǧūdala*, *Janfa almamy*)** — Rouge / nocturne. Sens : combat, impulsivité, trahison (*janfa*), audace.
13. **Conjunctio (`2112`, *al-Iǧtimāʿ*, *Badara Ali*)** — Blanc / diurne. Sens : réunion, accord, jonction, retrouvailles, objet retrouvé.
14. **Laetitia (`1222`, *al-Laḥyān*, *Adama*)** — Noir / diurne (« divine »). Sens : joie, réussite, bonne nouvelle, élévation.
15. **Tristitia (`2221`, *al-Inkīs*, *Mankusi*)** — Noir / nocturne. Sens : tristesse, deuil, abattement, fatalité.
16. **Fortuna Minor (`1122`, *al-Nuṣra al-ḫāriǧa*, *Kalalaw*)** — Blanc / diurne. Sens : secours extérieur, succès rapide mais instable ou dépendant d'autrui.
