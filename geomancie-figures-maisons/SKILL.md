# Les 16 Figures et les 16 Maisons (`geomancie-figures-maisons`)

## 1. Règles de lecture et d'intégrité

1. **Lecture verticale de haut en bas** : Feu (rang 1) → Air (rang 2) → Eau (rang 3) → Terre (rang 4). `1` = impair (`•`), `2` = pair (`••` ou `—`).
2. **Ne jamais fusionner `al-Ǧamāʿa` et `al-Iǧtimāʿ`** `[A]` :
   - `2222` = **الجماعة (*al-Ǧamāʿa* / Populus)** = l'Assemblée.
   - `2112` = **الاجتماع (*al-Iǧtimāʿ* / Conjunctio)** = la Conjonction.
3. **Ne jamais lisser les divergences entre traditions** : les jeux arabe (*Bulūgh*), mandé (Kassibo 1992), bambara de Ségou (Bertaux 1984) et latin/français (*Geomancie-Aide*) divergent sur plusieurs éléments, sexes et jours rituels. Toujours préciser la tradition citée.

## 3. Règles dérivées et sous-ensembles `[A]/[C]`

- **Sexe selon al-Ṭūkhī** (*Bulūgh*, Bāb II–III `[A]`) : « le masculin est le sortant (الخارج, tête = `1`), le féminin est l'entrant (الداخل, tête = `2`) ».
- **Humain vs Djinn** (Hébert 1961, p. 149 `[A]` → `[C]`) : somme des points **paire** (4, 6, 8) = **Humain** (*mògò seki*) ; somme **impaire** (5, 7) = **Djinn** (*jinne seki*).
- **4 Figures « Pures » (7 points, 1 seul rang simple)** `[C]` :
  - Feu : `1222` (*Laetitia*, rang 1 = `1`)
  - Air : `2122` (*Rubeus*, rang 2 = `1`)
  - Eau : `2212` (*Albus*, rang 3 = `1`)
  - Terre : `2221` (*Tristitia*, rang 4 = `1`)
- **4 Figures Symétriques (« Nobles » / *Horondenw*)** `[A]/[C]` : `1111` (*Via*), `1221` (*Carcer*), `2112` (*Conjunctio*), `2222` (*Populus*).
