# Glossaire Technique et Conventions de Translittération

## 1. Translittération arabe simplifiée (norme du projet)

`ḏ` = ذ · `ṯ` = ث · `ḫ` = خ · `ḍ` = ض · `ṭ` = ط · `ẓ` = ظ · `ʿ` = ع · `ʾ` = ء · `ḥ` = ح · `ṣ` = ص · `q` = ق · `ǧ` = ج.

## 3. Convention de notation dans les transcriptions

- Toujours noter chaque figure avec son nom suivi de son tracé binaire **de haut en bas** : ex. `al-Ṭarīq (1-1-1-1)`.
- Conserver les formules religieuses d'ouverture ou de clôture dans les traductions littérales sans les supprimer ni les moderniser.
- Ne pas remplacer les noms arabes par des équivalents latins dans une traduction directe d'un traité arabe.
